Phase 6: AI Audio Editor — Architecture

Hybrid approach: thin InpaintCoordinator reusing existing VAE + Diffusion actors

Inpainting Pipeline Flow
Input Audio (WAV/generated)
↓ VAEActor.encode()
Full Latents [B, T, 64]
↓ MaskBuilder
Unmasked Region
Original latents preserved
Masked Region
Noise injected (strength-scaled)
↓ LatentBlender (noise injection at strength level)
Noised Latents (masked region only)
↓ DiffusionActor / SFXDiffusionActor (denoise with conditioning)
Denoised Latents
↓ LatentBlender (composite: original unmasked + denoised masked)
Composited Latents
↓ VAEActor.decode()
Output Audio

Key Components

InpaintCoordinator
Thin actor sequencing encode → mask → noise → denoise → composite → decode. Owns undo stack.
MaskBuilder
Converts time range (+ optional freq band) into latent-space binary mask. Handles sample rate → latent frame conversion.
LatentBlender
Noise injection (strength-scaled) and final compositing. Pure math on MLXArrays.
EditHistoryManager
Multi-level undo/redo via [EditSnapshot]. Stores latent + audio pairs per edit.
Reused: VAEActor
Existing actor gains encode() method (currently decode-only). Used for both ACE-Step and SFX paths.
Reused: Diffusion Actors
DiffusionActor (ACE-Step) or SFXDiffusionActor — gains partial-noise start support for inpainting.

Conditioning Flow

Original Prompt → full conditioning (provides context for unmasked region)
Region Prompt → targeted conditioning (guides what the masked region becomes)
For ACE-Step: ConditioningActor produces encoder states from region prompt
For Stable Audio: CLAPEncoder encodes region prompt → [1, 512]
Full Repaint mode: mask covers entire duration, strength controls how much original structure is preserved
