Layout Notes

Position: DSP Palette lives below the AI controls section in the Edit tab's main content area (not in a separate inspector pane).

Behavior: Clicking an effect button expands its parameter panel inline. Only one effect panel open at a time. Last-used stays expanded with previous values.

Apply Target: Smart default — shows "Selection (1.2s–2.8s)" when region is selected, "Whole Track" otherwise. User can toggle.

Instant Apply: Trim to Selection, Delete Selection, and Normalize have no parameters — they apply immediately on click (with undo snapshot).
