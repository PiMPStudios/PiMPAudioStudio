# Contributing

PiMP Audio Studio is a private, proprietary project. It is not an open-source
project and does not accept unsolicited code, documentation, artwork, model,
dataset, or other copyrightable contributions.

Repository access does not authorize a person to modify, reuse, publish, or
distribute project materials. See [LICENSE](LICENSE) for the terms governing
authorized source access.

Before PiMP Studios accepts a contribution, the contributor and Professional
Interactive Media Productions LLC must enter into a written contribution or
intellectual-property agreement approved by PiMP Studios. This keeps ownership
clear and preserves the company's ability to license or relicense the project.

General bug reports and non-confidential feedback may be provided through a
channel approved by PiMP Studios. Do not include third-party confidential
information, copyrighted source code, private datasets, credentials, or model
weights in a report.
