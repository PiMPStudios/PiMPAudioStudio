# Legal Documents

These documents establish the current proprietary licensing foundation for
PiMP Audio Studio.

## Current Documents

- [`../../LICENSE`](../../LICENSE) is the operative proprietary source-code
  license and confidentiality notice for PiMP-owned repository materials.
- [`../../THIRD_PARTY_NOTICES.md`](../../THIRD_PARTY_NOTICES.md) separates
  third-party components and records the current direct dependency inventory.
- [`../../CONTRIBUTING.md`](../../CONTRIBUTING.md) explains that copyrightable
  contributions require a separate written agreement.
- [`source-access-acknowledgment.md`](source-access-acknowledgment.md) is a
  short acknowledgment template for specifically invited repository readers.
- [`eula-draft.md`](eula-draft.md) is a non-operative customer EULA draft for
  attorney review before binary distribution.

## Before Commercial Release

1. Have qualified counsel review the source license and EULA.
2. Complete a privacy/data-flow audit and publish a privacy policy.
3. Generate and bundle complete direct and transitive third-party notices.
4. Audit every downloadable model and remote-worker dependency separately.
5. Decide whether the App Store build uses Apple's standard EULA or a reviewed
   custom EULA, and apply the reviewed terms consistently to direct downloads.
6. Confirm that every employee, contractor, and outside contributor has a
   written confidentiality and intellectual-property assignment agreement.

These repository documents are drafting and operational aids, not a substitute
for advice from a licensed attorney.
