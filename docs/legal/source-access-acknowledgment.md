## Electronic Acceptance Option

For an electronic record, send the recipient the repository link and this
document, then ask the recipient to reply from their identified email account
with the following statement:

> I have read and agree to the PiMP Audio Studio Proprietary Source Code
> License, Version 1.0 dated July 24, 2026, and the Source Access
> Acknowledgment. My GitHub username is [USERNAME], and my access is limited to
> [AUTHORIZED PURPOSE].

Retain the complete message thread, date, recipient identity, and a copy of the
terms that were accepted. Obtain attorney guidance before relying on this
template for access to especially sensitive trade secrets or for recipients in
another jurisdiction.
