# Phase 6: AI Audio Editor — Design Spec

## Overview

AI-powered audio editing via masked latent inpainting and full-track repainting.
Users select a time region on a waveform, provide a text prompt describing what
the region should become, and the system regenerates that region while preserving
surrounding audio. Full repaint mode applies style transfer to the entire track.

**Architecture:** Hybrid — thin `InpaintCoordinator` actor reuses existing VAE and
diffusion actors with minimal additive changes. New code is limited to mask
construction, latent blending, undo management, and the Edit tab UI.

---

## Interaction Model

### Modes

- **Inpaint** (default) — user selects a time region, provides a region prompt,
  and the selection is regenerated in context
- **Repaint** — mask covers the full duration; strength slider controls how much
  of the original structure is preserved vs regenerated toward the new prompt

### Selection

- **Primary:** drag-to-select on waveform (time range)
- **Advanced:** collapsible frequency constraint panel with Low Cut / High Cut
  sliders (progressive disclosure). When active, the mask applies only to the
  specified frequency band within the time range.

### Prompts

- **Original Prompt** (read-only) — provides context for the unmasked region.
  Auto-filled from provenance when entering via "Edit This" from Generate tab.
- **Region Prompt** (editable) — describes what the masked region should become.
  In Repaint mode, this relabels to "Target Style."

### Strength & Guidance

- **Presets row:** Subtle (0.3 / 5.0), Moderate (0.6 / 7.0), Full (0.9 / 10.0)
- **Strength slider:** 0.0–1.0, controls noise injection level (how far from
  original). Maps linearly to diffusion start timestep.
- **Guidance Scale slider:** 1.0–15.0, controls prompt adherence during denoising.
- Selecting a preset sets both sliders; adjusting a slider deselects the preset.

### Pipeline Selection

- User chooses ACE-Step or Stable Audio for the edit operation
- Defaults from provenance (if audio was generated by Anvil) or ACE-Step for
  imported audio
- Consistent with existing `PipelineChoice` pattern in Generate tab

## UI Design

### Edit Tab Layout (top to bottom)

1. **Toolbar** — File open button, filename + metadata (duration, sample rate,
   channels), mode toggle (Inpaint / Repaint segmented control), pipeline picker,
   undo/redo buttons (with history popover showing last 5 edits)
2. **Waveform canvas** — stereo waveform with drag-to-select (orange highlight
   with time labels), playhead during playback, zoom +/- controls. Below:
   collapsible "Frequency constraint" with Low Cut / High Cut sliders.
3. **Prompt area** — two-column grid: left = Original Prompt (gray, read-only),
   right = Region Prompt (blue-themed, editable)
4. **Controls bar** — preset buttons (Subtle / Moderate / Full), strength slider,
   guidance scale slider, action button
5. **Action button** — dynamic label: "Inpaint Selection" in Inpaint mode,
   "Repaint Track" in Repaint mode

### Entry Points

- **Edit tab (standalone)** — open any audio file (WAV/MP3/OGG) from file picker
  or from history
- **"Edit This" from Generate** — button in PlayerView after generation. Jumps to
  Edit tab with audio pre-loaded + original prompt auto-filled from HistoryEntry

### Undo/Redo UX

- Toolbar buttons + Cmd+Z / Cmd+Shift+Z keyboard shortcuts
- Chevron on undo button opens popover with last 5 edits (description + timestamp)
- Each edit restores audio + latents atomically (no re-decode needed)

## Architecture

### Pipeline Flow

```text
Input Audio (WAV/generated)
    ↓ VAEActor.encode()
Full Latents [1, T, 64]
    ↓ MaskBuilder
Mask [1, T, 1] or [1, T, D]
    ↓ LatentBlender.injectNoise(strength)
Noised Latents (masked region only)
    ↓ DiffusionActor.inpaint() / SFXDiffusionActor.inpaint()
Denoised Latents
    ↓ LatentBlender.composite(original, denoised, mask)
Composited Latents
    ↓ VAEActor.decode()
Output Audio
```

### Components

| Component | Role | New/Modified |
|-----------|------|--------------|
| `InpaintCoordinator` | Thin actor orchestrating the pipeline, owns undo stack | New |
| `MaskBuilder` | Time/frequency → latent-space binary mask | New |
| `LatentBlender` | Noise injection + compositing (pure MLXArray math) | New |
| `TimestepMapper` | Strength → start timestep + truncated schedule | New |
| `EditHistoryManager` | Multi-level undo/redo with `[EditSnapshot]` | New |
| `VAEActor` | Gains `encode(audio:useMean:)` method | Modified |
| `SFXVAEActor` | Gains `encode(audio:)` method | Modified |
| `SFXVAEModel` | Gains encoder path (symmetric downsample blocks) | Modified |
| `DiffusionActor` | Gains `inpaint(startLatents:schedule:...)` method | Modified |
| `SFXDiffusionActor` | Gains `inpaint(startLatents:schedule:...)` method | Modified |
| `HistoryEntry` | Adds `pipeline` + `originalPrompt` fields | Modified |

### Conditioning Flow

- **ACE-Step pipeline:** `ConditioningActor.condition(text: regionPrompt, ...)`
  produces encoder states for the diffusion actor (reuses existing logic)
- **Stable Audio pipeline:** `CLAPEncoder.encode(text: regionPrompt)` produces
  `[1, 512]` conditioning vector
- Original prompt provides unmasked context; region prompt guides regeneration

### Full Repaint

Full repaint is inpainting where the mask covers the entire duration. No separate
code path — `MaskBuilder` produces an all-ones mask, and the pipeline proceeds
identically. Strength controls how much original structure is preserved.

## Core Algorithms

### MaskBuilder

Converts user's time selection (and optional frequency band) into a latent-space
binary mask.

- ACE-Step hop size: 2048 samples (downsample ratios 2×4×4×8×8)
- SFX hop size: product of `SFXVAEConfig.upsampleRatios`
- At 44100 Hz with ACE-Step, one latent frame ≈ 0.0464 seconds
- Output shape: `[1, T, 1]` (time-only) or `[1, T, D]` (with frequency band)
- Values: 1.0 = masked (regenerate), 0.0 = unmasked (preserve)
- Edge guards: clamp frames to valid range, reject startFrame >= endFrame

Frequency-to-channel mapping is approximate (latent channels don't correspond 1:1
to frequency bands, but provides empirically useful band isolation).

### LatentBlender

Two operations on MLXArrays:

**Noise injection:**

```text
noised = (1 - strength) * clean + strength * noise
result = clean * (1 - mask) + noised * mask
```

Only the masked region receives noise. Unmasked latents pass through unchanged.

**Compositing:**

```text
output = original * (1 - mask) + denoised * mask
```

After denoising, the denoised region replaces the masked area while unmasked
latents are preserved from the original.

### TimestepMapper

Maps strength to start timestep for the diffusion schedule:

- `strength=1.0` → start from full T (pure noise, complete regeneration)
- `strength=0.0` → start from 0 (no denoising, no change)
- Linear mapping: `startStep = totalSteps * strength`
- Returns truncated schedule (only timesteps from startStep onward)
- Fewer steps for low-strength edits = faster inference

Future refinement: cosine or power curve (`pow(strength, 0.7)`) if linear feels
too aggressive at low strengths.

### Seeded Noise

```swift
func seededNoise(shape: [Int], seed: Int?) -> MLXArray {
    if let seed { MLXRandom.seed(seed) }
    return MLXRandom.normal(shape)
}
```

Deterministic noise for reproducible edits when seed is provided.

## Existing Actor Modifications

All changes are purely additive — no existing method signatures or behavior change.

### VAEActor

```swift
public func encode(audio: MLXArray, useMean: Bool = true) -> MLXArray
```

Wraps existing `AutoEncoderOobleck.encodeMean()` / `encodeSample()`. Uses
`encodeMean` by default for deterministic inpainting. Audio input shape must match
the existing NLC convention used by the VAE.

### SFXVAEActor

```swift
public func encode(audio: MLXArray) -> MLXArray
```

Requires adding an encoder path to `SFXVAEModel` (symmetric to the existing
decoder: downsampling blocks mirroring the upsampling blocks).

### DiffusionActor

```swift
public func inpaint(
    startLatents: MLXArray,
    schedule: [Float],
    conditioning: ConditioningResult,
    config: DiffusionConfig,
    progressHandler: ((DiffusionProgress) -> Void)? = nil
) -> AsyncStream<DiffusionProgress>
```

Same diffusion loop as `generate()` but starts from partially-noised latents with
a truncated timestep schedule. CFG, APG, ODE/SDE stepping are unchanged.

### SFXDiffusionActor

```swift
public func inpaint(
    startLatents: MLXArray,
    schedule: [Float],
    conditioning: MLXArray,
    config: SFXDiffusionConfig
) -> AsyncStream<GenerationProgress>
```

Mirror of `DiffusionActor.inpaint()` for the Stable Audio pipeline.

## InpaintCoordinator

Thin orchestration actor that sequences the pipeline and manages state.

### Responsibilities

- Load audio from URL → VAE encode → store latents + audio
- Execute edits: mask → noise → denoise → composite → decode → push undo
- Route conditioning through existing actors based on pipeline choice
- Expose `AsyncStream<InpaintProgress>` for UI progress binding
- Provide undo/redo by restoring snapshots from EditHistoryManager
- Propagate errors via `.failed(String)` progress case

### State

- `currentLatents: MLXArray?` — latest latent state (for further edits)
- `currentAudio: MLXArray?` — latest decoded audio (for playback)
- `totalDuration: TimeInterval` — track length
- `sampleRate: Int` — sample rate of loaded audio
- `historyManager: EditHistoryManager` — undo stack (max 20 snapshots)

### loadAudio

Returns duration and sample rate so the UI can update immediately. Pushes the
initial state as the first undo snapshot.

---

## EditHistoryManager

### Properties

- `stack: [EditSnapshot]` — ordered edit history
- `currentIndex: Int` — pointer into stack
- `maxSnapshots: Int = 20` — memory cap
- `canUndo: Bool` / `canRedo: Bool` — for UI button state
- `recentEdits: [EditSnapshot]` — last 5 for toolbar popover

### Behavior

- **Push:** appends snapshot, discards any redo history beyond current index,
  drops oldest if over `maxSnapshots`
- **Undo:** decrements index, returns previous snapshot
- **Redo:** increments index, returns next snapshot
- Each snapshot stores audio bytes (instant restore) + latents (for re-editing
  from that state)

### Memory

Worst case: 20 snapshots × 31MB (3-min stereo WAV) ≈ 620MB. In practice, edits
target short regions and snapshots are smaller. Future optimization: store only
edited regions + diff against original.

## Scope

This phase delivers the full AI Audio Editor:

- Edit tab shell with toolbar, waveform, prompts, controls
- Waveform visualization with drag selection + playhead + zoom
- Frequency constraint panel (progressive disclosure)
- Inpaint and Repaint modes with mode-aware UI
- Full inference pipeline (encode → mask → noise → denoise → composite → decode)
- Pipeline routing (ACE-Step / Stable Audio)
- Presets + strength/guidance sliders
- Multi-level undo/redo with latent snapshots
- "Edit This" entry point from Generate tab
- Progress reporting via AsyncStream

### Out of Scope

- DSP editing (trim, fade, EQ, reverb) — Phase 7
- Spectrogram visualization (possible future enhancement)
- Batch editing / multi-region selection
- Real-time preview during parameter adjustment
